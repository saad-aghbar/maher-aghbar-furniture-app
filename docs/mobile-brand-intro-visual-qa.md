# Mobile brand intro — Netflix-style logo sting

Sequence:

1. Dark veil
2. Authentic logomark **slams** in (scale ~2.6 → 1) with light haptic
3. Brief hold
4. Veil lifts, logo settles into login header, form/chrome stagger in

Not a rising-line / stroke-draw intro.

Tap after ~500ms skips to final layout. Reduced motion: short fade. Logout: short logo+form reveal.
