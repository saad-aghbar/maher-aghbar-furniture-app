# Admin user guide (summary)

1. Sign in at `/ar/login` with a staff account.
2. Use the dashboard for delayed production, low stock, and pending approvals.
3. Manage customers under **Customers**.
4. Create quotations, submit for approval, approve, and send.
5. After customer acceptance, confirm the sales order to generate production.
6. Track inventory receipts/issues; balances change only via transactions.
7. Issue invoices and record payments under accounting modules.
8. Use **AI Intake** to draft RFQs from pasted text — always review before approve.
