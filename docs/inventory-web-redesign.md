# Inventory admin web redesign

Same domain model and terminology as mobile. Do not stretch the mobile layout onto desktop.

Use existing Admin Web design system: overview cards, filterable lists, dense tables where useful, drawers.

Screens: Overview, Raw Materials (four groups), Semi-Finished, Finished Goods, Warehouses, Transfers, Stock Counts, Transactions.

Workflow stage drawer: Advanced / Inventory (No / Semi-Finished / Finished Product, consume toggles). Product edit: track finished goods, default workflow, BOM, optional linked FG item.

Production order: compact inventory flow. Returns: quarantine fate UI.
